# --------------------------------------------------------------------
# Rt.01 — CUDA driver cuInit process-lifetime state (260 bytes/call)
# --------------------------------------------------------------------
# Why: libcuda.so.1 allocates internal driver state on the first
# cuInit() call (driver handle, device list, mutex pool). The CUDA
# runtime exposes no teardown API — the allocation is tied to the
# process and reclaimed by the kernel at exit. Mapanare cannot free it.
# How to apply: 39_gpu_detect / 40_gpu_tensor call gpu_available()
# which bottoms out in mapanare_gpu_init → cuInit.
leak:mapanare_gpu_init
