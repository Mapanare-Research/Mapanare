# Delta Review — v4.45.0 Tensor Slicing

**Feature:** Tensor reductions + slicing (`t[0..2, _]`)
**Reviewers:** Rattler (runtime) + Coral (syntax)

## Changes

- 12 reduction runtime functions (sum/mean/max/min/argmax/argmin × f64/i64)
- `IndexItem` AST node (scalar/range/wildcard kinds)
- `__mn_tensor_slice` runtime with coordinate mapping
- Semantic shape inference for sliced results
- Range detected via RangeExpr, wildcard via Identifier("_")

## Rattler — PASS WITH NOTES

- Coordinate mapping in `__mn_tensor_slice` is correct (row-major)
- Bounds validated: negative starts clamped, ends clamped to shape
- Zero-width slices produce zero-size tensors (correct)
- Reduction empty-tensor guards correct (sum=0, mean/max/min abort)
- Note: stride computation recomputed per element (performance, not correctness)

## Coral — PASS

- Grammar unchanged — LALR-safe, no new tokens
- RangeExpr piggybacks on existing range syntax
- `_` wildcard convention matches Rust/Python, disambiguated in transformer
- No ambiguity with existing `_` uses (match wildcards are in different parse context)

## Combined Verdict: PASS WITH NOTES
