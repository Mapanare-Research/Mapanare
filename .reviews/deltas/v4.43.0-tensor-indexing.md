# Delta Review — v4.43.0 Tensor Indexing

**Feature:** Multi-dimensional tensor indexing `t[i, j, k]` with bounds checking
**Reviewers:** Rattler (runtime-crossing lens)

## Changes

- Grammar: `index_expr` extended to `expr (COMMA expr)*`
- AST: `IndexExpr.index` → `IndexExpr.indices` (14 call sites migrated)
- Semantic: rank-match enforcement; under/over-rank → error; list/map multi-index → error
- Lowering: tensor get/set → variadic Call instructions
- Runtime: 4 `__mn_tensor_{get,set}_{f64,i64}_nd` functions with per-dim bounds check
- LLVM: variadic call emission `(ptr, i64, ...)`

## Rattler — PASS WITH NOTES

- Variadic-via-pointer approach is reasonable and idiomatic
- Bounds check aborts with useful messages (dimension, index, shape)
- Flat offset computation correct for row-major (right-to-left stride accumulation)
- LLVM call signatures consistent with C implementation
- Note: rank > 16 truncation was silent → **fixed** with explicit abort guard per review
