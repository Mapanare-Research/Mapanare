# v4.47.0 — AI/LLM Stdlib

Unified chat interface across 5 LLM providers (OpenAI, Anthropic, Ollama, custom, streaming). Fixed the two Arc 3 panel bugs (slicing inttoptr CRITICAL, scalar-tensor operand swap MEDIUM). ChatChunk streaming with SSE and NDJSON parsing. Environment-based configuration defaults.

## Key Changes
- Fixed v4.46.0 CRITICAL: `emit_llvm_text.py` allocates stack arrays for tensor slice pointers
- Fixed v4.46.0 MEDIUM: 4 reverse scalar runtime functions (`rsub`/`rdiv`) for non-commutative ops
- `ChatChunk` type with `delta`, `finish_reason`, `is_done` fields
- `chat_stream()` with SSE (OpenAI/Anthropic) and NDJSON (Ollama) parsing
- `default_config()` reads `MAPANARE_LLM_*` env vars; defaults to Ollama localhost
- `split_lines()` helper for streaming response parsing
- `stdlib/ai/llm.mn`: 1,710 -> 1,909 lines
- Examples: `basic_chat.mn`, `basic_stream.mn`
