# v4.48.0 — Structured Output

Compile-time struct reflection via `__struct_meta::<T>()` turbofish intrinsic. Generates JSON schema for any struct type T at compile time -- zero runtime overhead, embedded as `[N x i8]` constant in LLVM IR. `extract_with_schema()` sends schema to LLM, validates response, retries on malformed JSON.

## Key Changes
- `__struct_meta::<T>()` builtin: semantic validation (1 type arg, 0 value args, returns String)
- Lowering: iterates struct fields, maps types to JSON Schema (`String->string`, `Int->integer`, `Float->number`, `Bool->boolean`, `List->array`, `Option<T>->not required`)
- Schema embedded as compile-time constant string in LLVM IR module
- `extract_with_schema(config, schema, text, max_retries)` in `stdlib/ai/llm.mn`
- `ExtractError` enum: LlmFailed, ParseFailed, ValidationFailed, RetriesExhausted
- `validate_json_shape()` for JSON object boundary detection
- `stdlib/ai/llm.mn`: 1,909 -> 2,025 lines
