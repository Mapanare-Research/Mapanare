# v4.102.0 — First Native Async Run

First native async execution in the history of the project. All 3 async golden tests (`55_async_basic.mn`, `56_async_await.mn`, `57_real_await.mn`) compile, link, and run natively with expected output (42, 43, 110). Valgrind clean. Dockets #3 (async can't link) and #6 (runtime symbol export) closed.

## Key Changes
- Two bugs fixed in series, same symptom (NULL function pointer call):
  - Bug 1: `mn_coro_is_done` checked wrong frame offset (handle[16] instead of handle[0])
  - Bug 2: `_do_block_on` reloaded coroutine handle from a slot the coroutine overwrites with its return value
- Fix for Bug 1: `return *(void **)handle == NULL;` (3 lines)
- Fix for Bug 2: cache handle before resume, reuse cached handle after
- 3/3 async goldens run natively with expected output
- Valgrind clean: zero errors, zero leaks on 55_async_basic
- CI step added for async golden verification
