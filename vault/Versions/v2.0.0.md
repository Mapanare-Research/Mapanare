# v2.0.0 — Beyond the Machine

WebAssembly backend, GPU compute (CUDA + Vulkan via dlopen), and mobile cross-compilation targets. The compiler expanded from Linux-only LLVM to 9 platform targets. Python backend formally deprecated.

## Key Changes
- WASM emitter: `emit_wasm.py` (~2,785 lines), MIR to WAT, WASI support, JS bridge, wasm-ld linking
- GPU compute: CUDA Driver API + Vulkan loaded dynamically (no compile-time SDK dependency)
- Mobile targets: iOS (aarch64-apple-ios), Android ARM64 + x86_64
- Cooperative agent scheduler for mobile, epoll event loop, memory profiling
- 9 cross-compilation targets total
- Python backend deprecated
- 4,465+ tests
