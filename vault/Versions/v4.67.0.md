# v4.67.0 — Coroutine DESIGN.md

Design-only release. No code changes, no functional changes, no test changes. DESIGN.md (8 sections, ~7,500 words) documents the LLVM coroutine strategy: switched-resume ABI, cooperative scheduler, Future<T> representation, pass pipeline. 8 key decisions locked for arcs 8+9.

## Key Changes
- DESIGN.md: 8 sections + 3 appendices covering LLVM coroutine intrinsics
- Decision 1: Switched-resume ABI (`llvm.coro.id`) for generic handles and HALO elision
- Decision 2: Inline cooperative scheduler (matches agent scheduler)
- Decision 3: `Future<T>` as `{i8 state, ptr payload}`
- Decision 4: Rely on LLVM `-O1` default pipeline (no explicit pass ordering)
- Decision 5: Both `async fn` and explicit `Future<T>` supported
- Decision 6: Dedicated `AsyncFnDef` AST node (not a flag on FnDef)
- Decision 7: Async debug info deferred to v5.x
- Decision 8: Self-hosted compiler lags by 1-2 releases
- Informal review: Rattler, Viper, Cobra, Coral all APPROVED
