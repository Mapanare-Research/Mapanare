# v4.0.0 — Production Release

The "other people can use it" release. A user can write a CLI program, fetch data over HTTP from a native binary, transpile .py/.php/.ts/.go files, install packages, and get useful error messages with line numbers and Levenshtein suggestions. 40/40 golden tests, 4,845+ pytest.

## Key Changes
- CLI programs: read stdin, process files, write output -- all native
- HTTP client: fetch data from native binaries, no Python runtime
- Transpilation: .py, .php, .ts, .go to Mapanare end-to-end
- Package manager: `mapanare install` with dependency resolution
- GPU: `@gpu` annotated functions with graceful CPU fallback
- Error messages: line numbers, Levenshtein-based suggestions
- All C runtime modules linked into native binaries (IO, runtime, GPU)
- `read_line()` for interactive programs
