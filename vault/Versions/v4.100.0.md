# v4.100.0 — Tagged-Pointer UB Fix (Partial)

Phase A release 1. Fixes docket #1: [[tagged-pointer-ub]].

## What Shipped

- `MnString` bitfield: `{ const char *data; uint64_t len:63; uint64_t is_heap:1; }`
- Removed `mn_tag_heap` / `mn_is_heap` / `mn_untag`
- ABI preserved at 16 bytes (see [[ADR-001 Bitfield vs int8 for is_heap]])
- `test_greet_string_round_trip` passes

## Deviation

Plan said `int8_t is_heap` — that grows MnString to 24 bytes, breaks SysV AMD64 ABI. Bitfield is equivalent fix without ABI cliff.

## Known Limitation

Output corruption persists. Confirmed pre-existing (pristine v4.99.0 binary has same corruption). Root cause was [[list-indexing-bug]], fixed in [[v4.101.0]].
