# v4.107.0 — Cross-Language Benchmarks

Pure measurement release. Zero Mapanare code changes. 12 new benchmark programs (6 Go + 6 C) plus rewritten harness publish the full six-column comparison: C (gcc -O2), C (clang -O2), Rust -O, Go, Mapanare O2, Python 3.12 across 6 workloads. Geometric mean: Mapanare is 9.5x slower than C gcc, 2.8x slower than Rust, 1.3x slower than Go, 44.6x faster than Python.

## Key Changes
- 6 Go programs: fib_recursive, quicksort, struct_alloc, enum_match, prime_sieve, string_concat
- 6 C programs: same workloads, compiled with both gcc -O2 and clang -O2
- Harness: 10 runs per config, median of middle 8, `/usr/bin/time -v` for accurate per-process peak RSS
- Pure compute (fib, prime_sieve): on par with Rust
- enum_match: 27x slower (confirms [[v4.106.0]] Rt.1 boxed-enum overhead)
- string_concat: 1,278x slower (confirms StringBuilder as v4.108.0 target)
- Pre-existing `List<Int>` indexing bug surfaced (docket Qs.1): quicksort produces wrong checksum
- 35/36 benchmark cells correct
- Report at `benchmarks/cross_language/FULL_COMPARISON.md`
