# v4.34.0 — Match Decision-Tree Rewrite

Replaced the entire match-lowering pipeline with a Maranget decision-tree algorithm. Exhaustiveness checking now constructs witness patterns for missing arms. DESIGN.md-first: algorithm, data structures, and emission rules documented before implementation.

## Key Changes
- `pattern_matching.py` (480 lines): PatternRow, PatternMatrix, DecisionTree, Maranget builder
- `_lower_match` replaced wholesale with decision-tree lowering in `lower.py`
- Semantic exhaustiveness via `build_decision_tree` + `DTFail` detection
- Witness patterns in diagnostic messages ("missing case: None", "missing case: Err(_)")
- Unreachable arm warnings, cycle guard for recursive enum types
- 11 exhaustiveness tests (6 positive, 3 negative, 2 diagnostic quality)
- Golden test `48_match_nested_exhaustive.mn`
- Arena allocator thread-safe via spinlock
- `__mn_read_line` uses `getline(3)` (no more 4KB truncation)
- `MN_PROFILE_FREE` wired via `__mn_free_sized(ptr, size)`
