# v0.6.0 — Compiler Infrastructure

MIR pipeline introduced: SSA-based intermediate representation with ~35 instruction types, optimizer passes (O0-O3), and dual emitters. Bootstrap frozen at this version -- `bootstrap/` snapshot becomes the stable reference for all future self-hosted work.

## Key Changes
- MIR core: typed SSA IR, basic blocks, explicit terminators, verifier, pretty-printer
- AST-to-MIR lowering: `lower.py` (1,397 lines), all AST constructs
- MIR optimizer: constant folding, DCE, copy propagation, branch simplification
- Dual MIR emitters: Python (`emit_python_mir.py`) and LLVM (`emit_llvm_mir.py`)
- Bootstrap frozen: `bootstrap/` directory snapshot, three-stage verification design
- 2,500+ tests (71 MIR lowering + 61 optimizer tests)
