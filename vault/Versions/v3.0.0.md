# v3.0.0 — La Culebra Se Muerde La Cola

Radical syntax overhaul: indentation-based, bilingual keywords (Spanglish/English), `tipo`/`modo` unification. C emit backend added for portable bootstrapping. Zero backwards compatibility -- zero users to break.

## Key Changes
- Indentation-based syntax replacing braces (~25% token reduction)
- Bilingual keywords: `fn`/`funcion`, `if`/`si`, `else`/`sino`, `for`/`cada`
- `tipo`/`modo` unification: struct+enum merged into `tipo`, trait into `modo`
- `@Agent` decorator syntax replacing `agent` keyword
- C emit backend (`emit_c.mn`) for bootstrapping without LLVM dependency
- Migration tool for v2.x to v3.x syntax conversion
