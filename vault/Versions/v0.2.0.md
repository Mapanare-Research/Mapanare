# v0.2.0 — Self-Hosting

First self-hosted compiler modules: 5,800+ lines of `.mn` covering lexer, parser, semantic checker, and LLVM emitter. The compiler began writing itself.

## Key Changes
- Self-hosted compiler: lexer, parser, semantic, emit_llvm (recursive descent, not Lark)
- LLVM string/list codegen: concat, eq, len, slice, index, push, get, set
- C runtime foundation: lock-free SPSC ring buffers, thread pool with work stealing
- Constructor pattern established: `let r: T = first_field; return r`
- Builtins on LLVM: `str()`, `int()`, `float()` conversion functions
