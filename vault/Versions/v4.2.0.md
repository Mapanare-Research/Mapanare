# v4.2.0 — Clean House

Deleted 13,263 lines of dead emitters and unified the pipeline to a single LLVM text emitter. Three dead LLVM emitters (`emit_llvm.py`, `emit_llvm_mir.py`, `emit_python.py`) plus the broken self-hosted C emitter (`emit_c.mn`) removed. The `--no-mir` and `--emitter` CLI flags eliminated.

## Key Changes
- Deleted `emit_llvm.py` (2,883 lines) -- AST-based llvmlite emitter
- Deleted `emit_llvm_mir.py` (5,297 lines) -- MIR-based llvmlite emitter
- Deleted `emit_python.py` (1,239 lines) -- AST-based Python transpiler
- Deleted `emit_c.mn` (755 lines) -- broken self-hosted C emitter
- Removed `--no-mir` and `--emitter` CLI flags, all `use_mir` parameters
- 73 files changed, net ~13,263 lines removed
- 4,424 tests pass, 78 xfailed (PythonMIREmitter gaps)
