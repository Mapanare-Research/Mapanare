# v4.49.0 — Embeddings + RAG Helpers

Validated and tested the two existing stdlib AI modules: `embedding.mn` (933 lines, vector embeddings with OpenAI/Ollama, cosine/dot/euclidean similarity, linear-scan vector store) and `rag.mn` (484 lines, sentence/paragraph/fixed-size chunking, multi-document support, token budgeting). Added comprehensive test suites.

## Key Changes
- `stdlib/ai/embedding.mn`: EmbedProvider (OpenAI, Ollama, Custom), embed/embed_batch, VectorStore with top-k retrieval
- `stdlib/ai/rag.mn`: chunk_text, chunk_by_sentences, chunk_by_paragraphs, Document type, RetrievalContext, augment_prompt, estimate_tokens
- Vector math: dot_product, cosine_similarity, euclidean_distance, normalize, magnitude, vector_add, vector_scale, vector_mean
- 22 embedding tests (compilation, types, API surface, vector math, vector store)
- 15 RAG tests (compilation, chunking, context, prompt augmentation, UTF-8 safety)
