Mapanare calls itself AI-native because agents, signals, streams, and tensors are language primitives, not library add-ons. The stdlib provides a unified LLM interface (OpenAI, Anthropic, Ollama), structured extraction via compile-time JSON schema generation, vector embeddings with cosine similarity search, and RAG helpers for chunking and context building. An AI application in Mapanare looks like regular code, not framework glue.
