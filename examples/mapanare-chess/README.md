# Cascabel has moved

The Mapanare chess engine is now a standalone project:

**[Mapanare-Research/cascabel](https://github.com/Mapanare-Research/cascabel)**

Its Mapanare source, build instructions, chess tests, CI, and releases live
in that repository. Cascabel builds against a pinned Mapanare release and
does not require a checkout of this compiler repository.

The original implementation remains available in
[Mapanare v5.54.1](https://github.com/Mapanare-Research/Mapanare/tree/v5.54.1/examples/mapanare-chess).
